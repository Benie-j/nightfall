## Ressources utilisées

- `soldier.glb` : modèle militaire riggé de BAMEN, licence CC BY 4.0.
- `m4a1_fp.glb` : modèle M4A1 et bras FPS de Firewarden / bumstrum,
  licence CC BY 4.0 selon les crédits du dépôt source.
- `covered_car.glb` : modèle Poly Haven, licence CC0.
- `concrete_color.webp`, `concrete_normal.webp`,
  `concrete_roughness.webp` : texture Concrete034 d'ambientCG, CC0.

Les ressources ont été sélectionnées individuellement.
Nightfall n'intègre ni le moteur Three.js, ni le code HTML/JavaScript
du projet source.
